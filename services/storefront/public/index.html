    Chaos & Crash Testing Panel

    Each button breaks something on purpose. Watch the status bar above, then follow the trail in Datadog.

    App Cross-Service Bug

    Trigger Cascading Promo Null Error

    Checks out with LEGACY_VIP: storefront → checkout → promo. promo-service answers 200 OK with a null discount, so checkout-service throws a TypeError (500). The error surfaces in checkout; the cause is in promo.

    App Process Crash

    Kill Promo Service Process (OOM / Fatal Exit)

    promo-service allocates memory past its container limit and exits. Docker restarts it (restart: unless-stopped). Storefront and inventory stay up; orders without a promo code still go through.

    Database Code Bug

    Trigger Inventory DB Schema / Query Crash

    Asks inventory-service for an audited stock reservation. Its SQL references a column that doesn't exist (reserved_audit_flag) with a bad boolean cast, so inventory-db rejects it (500). Real orders over $500 take this path too.

    Database Resource Crash

    Exhaust Orders DB Connections & Row Lock

    checkout-service opens transactions that hold a FOR UPDATE lock on the order counter and take every pool connection. New orders wait, then time out. Everything is rolled back after the hold time.
